# 通用项目文档规则

长期项目文档放在 `docs/`，包含以下文档；设计系统、决策记录和资料归档按项目实际需要设置。

## 文档清单

| 文档 / 目录 | 应包含的内容 |
|---|---|
| **`README.md` — 文档索引** | 文档清单、各文档职责与内容边界、阅读入口、关联关系，以及命名和维护约定。 |
| **`PRD.md` — 产品需求** | 项目背景与目标、成功标准、目标用户与使用场景、功能清单与行为要求、内容或数据来源、最小可用版本范围、后续版本方向、非功能性需求、明确不做的事项、风险与未决问题。 |
| **`Architecture.md` — 技术架构** | 总体架构与运行方式、技术栈及使用边界、模块划分、路由或接口结构、数据模型与校验规则、数据流与状态管理、目录与资源组织、构建与部署方案、测试与质量门禁、监控与运维策略。 |
| **`DesignSystem.md` — 设计系统** | 视觉原则、色彩与语义令牌、字体与排版层级、间距与栅格、尺寸与形状规范、页面布局、组件表现、交互状态与反馈、响应式规则、主题策略、可访问性要求，以及设计令牌与样式实现的职责边界。 |
| **`ImplementationPlan.md` — 实施计划** | 实施阶段与步骤顺序、每步目标与范围、前置条件、依赖文档、交付物、验证方式与完成标准，以及执行状态、阻塞项和剩余工作。 |
| **`CHANGELOG.md` — 变更记录** | 未发布变更与已发布版本历史、版本号与发布日期，以及按新增、变更、弃用、移除、修复、安全分类的显著变更。 |
| **`decisions/` — 关键决策记录（ADR）** | 每项高变更成本决策独立成文，包含决策标题、状态、日期、决策者、背景、最终选择、正负面后果、风险与缓解措施、替代方案及未采用理由、相关资料和替代关系。 |
| **`decisions/_Template.md` — 决策模板** | 决策记录的统一章节结构、字段说明和填写提示。 |
| **`references/` — 外部参考资料** | 外部文档、讨论和方法论的原始资料，以及来源信息、用途说明和关联文档。 |
| **`research/` — 内部研究材料** | 具有持续追溯价值的方案比较、实验结果、原型、评审记录与截图，以及与正式结论的关联。 |

## 内容归属边界

- **产品需求**回答“为谁做、做什么、做到什么程度”。
- **技术架构**回答“如何组织、实现和交付”。
- **设计系统**回答“看起来怎样、操作起来怎样”。
- **实施计划**回答“按什么顺序完成、如何验证完成”。
- **决策记录**回答“为什么这样选、接受了哪些取舍”。
- **变更记录**回答“已经发生了哪些显著变化”。
- **参考与研究材料**保留依据和过程，不替代正式规范。
- 同一规则只在一个权威文档中完整定义，其他文档使用链接引用；编码约定放在 `AGENTS.md` 或可执行工具配置中。
